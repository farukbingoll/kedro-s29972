# Google Colab + Linear Regression

Predict apartment prices (thousands of PLN) from floor area (m²).

## Run
Upload `colab_regression.ipynb` at https://colab.research.google.com and select
Runtime → Run all. Upload `apartments.csv` in the Files panel to use the local
copy. If absent, the notebook loads the original tutorial CSV automatically.
For local use: install `requirements.txt`, open the notebook in Jupyter and run
all cells from this directory. The delivered notebook includes executed outputs.

## Completed work
- CSV loading and inspection (10 rows from the supplied file).
- Linear regression training, coefficients and predictions for 40/60/80/100 m².
- Regression plot saved as `regression.png`.
- Price per m² in PLN and its plot.
- MAE/MSE plus a quadratic feature and model comparison.
- Leave-one-out cross-validation to distinguish training fit from prediction.

Outputs: `regression.png`, `price_per_m2.png`, `model_comparison.png` and
`model_comparison.csv`. All can be regenerated by running the notebook.
The data is a tiny teaching sample and does not support real property valuation.

Source: https://github.com/PRO-D-PJATK/tutorials/tree/main/google-colab-linear-regression
